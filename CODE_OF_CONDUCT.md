# Code of Conduct

Have fun with the code and software features, and don't be a dick.

That is the whole rule. If you need it spelled out: criticise code, not people;
assume the other person is trying to help; and if someone asks you to stop,
stop.

Problems go to the repository owner through a [private security
advisory](https://github.com/chememjc/VoxelMill/security/advisories/new) or a
direct message. The owner decides what happens next, up to and including
blocking an account.
